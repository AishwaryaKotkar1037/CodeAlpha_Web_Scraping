# Web Scraping and Analysis of Books Data

## Introduction

This project demonstrates web scraping using Python,
BeautifulSoup and Requests.

The project collects book information from a public
practice website and creates a structured dataset.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib

## Data Collected

- Book Title
- Price
- Rating
- Availability
- Product URL

## Methodology

1. Access the website using Requests.
2. Parse HTML using BeautifulSoup.
3. Extract book information.
4. Store the information in a Pandas DataFrame.
5. Export the dataset to CSV.
6. Clean and analyze the data.
7. Create visualizations.

## Results

The project successfully collected book information
from multiple webpages and created a structured CSV dataset.

## Conclusion

Web scraping can be used to collect publicly available
information and convert unstructured web data into a
useful dataset for analysis.
